# LIMN Education

LIMN Education is LIMNMEDIA's developing educational platform for the art, craft, science, and technology of stop-motion animation.

The first working course is **Fundamentals of Stop-Motion Camera**. The goal is to build and teach a complete, useful course, then generalize the educational patterns demonstrated by real use.

## Status

This repository currently contains project principles and planning documentation, not a finished course or deployed LMS. Frappe is an implementation choice for the first educational slice, not the definition of the educational content.

## Contributions and privacy

Do not commit student information, client production materials, private lesson media, credentials, machine-specific configurations, financial records, or unlicensed third-party content. Publish educational source and assets only after editorial and rights review.
